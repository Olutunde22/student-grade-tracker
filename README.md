# Student Grade Tracker

A simple browser-based app for tracking student grades using HTML, CSS, and JavaScript.

## Features

- Add students with name and grade
- Prevent duplicate student names
- Validate input fields
- Persist data with `localStorage`
- Display and update average grade
- Delete students from the list

## Project Structure

- `index.html` - app structure and UI
- `style.css` - app styling
- `script.js` - app logic and data handling

## Notes

- To reset the app data, clear `localStorage` for this page in your browser dev tools.
- To view the deployed version, visit [Student Grade Tracker](https://olutunde22.github.io/student-grade-tracker/).
